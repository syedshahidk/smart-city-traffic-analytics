
# Real-Time Smart City Traffic Analytics

## Project Overview

A Big Data Analytics project that processes
historical and streaming traffic data to
analyze road congestion and predict future
traffic conditions.

## Problem Statement

Urban traffic congestion creates challenges
for transportation systems.

This project uses Big Data technologies to
collect, process and analyze traffic data
continuously and predict congestion patterns.

## Objectives

- Collect and process traffic datasets.
- Implement real-time data ingestion using Kafka.
- Process traffic streams using Apache Spark.
- Store historical data using Hadoop HDFS.
- Predict traffic congestion using Machine Learning.
- Visualize analytics through an interactive dashboard.

## Technology Stack

- Python
- Apache Kafka
- Apache Spark
- Hadoop HDFS
- PostgreSQL
- Scikit-learn
- Streamlit

## Project Structure

- datasets: Historical and processed datasets
- data_ingestion: Traffic data collection
- stream_processing: Real-time Spark processing
- storage: Data storage and database operations
- analytics: Traffic analysis and prediction
- dashboard: Interactive dashboard
- tests: Testing modules
- docs: Project documentation
